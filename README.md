# Petualangan Aljabar

Game pembelajaran berbasis web untuk siswa SMP kelas VIII tentang **bentuk aljabar**.
Soal diambil dari instrumen Pre-test dan Post-test Literasi Matematika.

## Isi game
| Misi | Indikator | Skor |
|---|---|---|
| 1. Paket Alat Tulis | Mathematical Reasoning | 6 |
| 2. Pagar Kebun Pak Budi | Formulating Situations Mathematically | 6 |
| 3. Menyederhanakan Ekspresi A | Employing Mathematical Concepts, Facts, and Procedures | 6 |
| 4. Periksa Pekerjaan Sinta | Interpreting, Applying, and Evaluating Mathematical Outcomes | 6 |
| | **Total** | **24** |

Setiap misi dipecah menjadi 6 langkah penyelesaian sesuai kisi-kisi penskoran.
Siswa memilih langkah yang benar, mendapat umpan balik dan pembahasan,
lalu melihat skor total serta skor per indikator di akhir permainan.

## Cara menjalankan
Buka file `index.html` di browser. Tidak perlu instalasi apa pun.

## Teknologi
HTML, CSS, dan JavaScript murni.
